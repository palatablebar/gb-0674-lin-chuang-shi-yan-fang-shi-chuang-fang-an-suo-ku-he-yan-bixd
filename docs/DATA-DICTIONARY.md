# 访视与冻结定义

样例均为虚构编号，无身份信息。受试者入组日期由subjects表唯一确定，记录中的入组基准必须完全一致。采样日期和入组日期均转为Asia/Shanghai日历日期，差值为访视日；时刻先统一UTC。
方案选择按当前受试者assignment和该次发生时刻查半开生效窗，匹配必须唯一，不能使用全局最新方案。v1访视V1=[5,10)、V2=[12,17)；v2为[6,11)、[13,18)。受试者00001于10月10日转v2，其他受试者仍用v1。
PRIMARY计入访视完成，RETEST只替代该次测量值。首次记录必须唯一且在访视窗内。缺首次访视、重复首次和窗外访视均阻断，复检不能填补漏访或消除原偏离。
复检须引用同受试者同访视的PRIMARY，晚于原采样且不超过72小时，版本必须更高。同最高版本复检冲突时保留原结果并阻断。所有检验值以mg/dL输出，g/L乘100。
终止登记来自context.terminations，含subject、status（CONFIRMED研究医生确认/VERBAL中心口报）、terminated_at（Asia/Shanghai日历日）、reported_by、confirmed_by。只有CONFIRMED影响应访：访视窗始日严格晚于终止日才免除，终止日当天窗已开启仍应访；VERBAL不缩短任何应访，避免口报提前掩盖终止前漏访，页面标注“口报仍应访”。终止前完成与终止后已采记录一律保留，终止后记录不隔离不判偏离；终止前缺首次访视等缺口继续阻断。免除按(受试者,访视)去重，同一终止重算或重试不重复扣减；非法终止登记（受试者不存在、状态无效、日期不可解析、早于入组）作为TERMINATION_*配置问题阻断，不静默放行。
锁库须所有规定访视完成，无偏离、复检问题和隔离行。应访总数＝受试者数×规定访视数，恒等于“应访＋终止免除”；闸门依据（gates）逐条列示放行或阻断原因，全批只有一个锁库结论。规则版本变更会改变输入摘要与批号，旧锁库结论失效，须按不可变输入快照重算。冻结包包含每条选定结果、原始行号、方案版本、访视窗与终止免除依据。此工具只验证试验数据完整性，不做诊断判断或生产锁库。
